# Release 0.1.0 - 2026-08-19

## Điểm nổi bật
Phiên bản đầu tiên của `todo-cli` — CLI quản lý việc cần làm tối giản, dùng làm project mẫu để chạy thử và xác nhận toàn bộ khung quy trình phát triển phần mềm của repo (requirements → design → task → code → review → PR → release).

## Thêm mới
- Lệnh `add`, `list`, `done`, `delete` để quản lý việc cần làm.
- Lưu dữ liệu vào file JSON local, giữ nguyên qua các lần chạy.
- Báo lỗi rõ ràng, không crash khi thao tác với id không tồn tại hoặc file dữ liệu bị hỏng.
